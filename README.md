# Full-Stack Bootcamp Curriculum

A mentor-led, project-based curriculum that takes students from **zero programming experience** to building real-world web and mobile applications with the modern JavaScript ecosystem (MERN + React Native).

## How to Use This Repository

- **`wiki/`** — Copy each markdown file into your [GitHub Wiki](https://docs.github.com/en/communities/documenting-your-project-with-wikis/about-wikis). Start with `Home.md` as the wiki home page.
- Each **week** is one self-contained phase with daily lessons, exercises, homework, and mentor notes.

## Course Stack

| Layer    | Technology              |
|----------|-------------------------|
| Frontend | HTML5, CSS3, JavaScript, React |
| Backend  | Node.js, Express        |
| Database | MongoDB, Mongoose       |
| Mobile   | React Native (Expo)     |
| Auth     | JWT                     |
| Deploy   | Vercel, Render, Atlas   |

## Teaching Model

- **Pace:** ~15–20 hours per week (part-time friendly)
- **Style:** Project-based — every lesson ends with something working
- **Sessions:** 2× live mentor sessions + solo practice + 1 async code review per week
