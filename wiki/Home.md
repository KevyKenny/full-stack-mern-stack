# Full-Stack Bootcamp — Course Wiki

Welcome to the **Full-Stack Bootcamp** wiki. This curriculum is designed for absolute beginners and taught one week per phase.

---

## Who Is This For?

- Students with **little or no programming experience**
- Mentors teaching a friend or small group
- Anyone learning the modern JavaScript path: HTML → CSS → JS → React → Node → MongoDB → React Native

---

## How the Wiki Is Organized

Each week page includes:

1. Learning objectives
2. Concepts to teach
3. Daily lesson plan (Mon–Sun)
4. Practical coding exercises
5. Mini project
6. Homework
7. Common mistakes beginners make
8. Best practices
9. Assessment quiz
10. Mentor notes
11. Resources for further learning

---

## Weekly Phases

| Week | Page | Focus | Hours |
|------|------|-------|-------|
| **1** | [[Week-01-Computer-Fundamentals]] | Environment, terminal, Git, GitHub | 12–15h |
| **2** | [[Week-02-HTML5]] | Semantic HTML, forms, tables, a11y | 15–18h |

---

## Critical Path

```
Week 1: Tooling & Git  →  Week 2: HTML  →  Week 3: CSS  →  Week 4–5: JavaScript  →  React  →  Backend  →  Deploy
```

> **Rule:** Do not skip Week 1. A student who cannot use the terminal and Git will struggle with everything after.

---

## Mentor Quick Start

1. Clone this repository and enable the GitHub Wiki.
2. Copy each file from the `wiki/` folder into your wiki pages.
3. Set `Home.md` as your wiki home page.
4. Run **2× 90-minute live sessions** per week plus async homework review.
5. Student must complete the **mini project** and **quiz** before advancing.

---

## Student Quick Start

1. Read [[Week-01-Computer-Fundamentals]].
2. Install VS Code and Git on Day 1 — do not skip ahead.
3. Push your first project to GitHub by end of Week 1.
4. Complete every **Deliverable** listed at the bottom of each week page.
